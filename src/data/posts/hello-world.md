# 你好，世界

开始写博客这件事，我拖了整整三年。

不是因为没有时间，而是因为总在等待一个「完美」的起点：完美的主题、完美的域名、完美的第一篇文章。后来才意识到，这种完美主义本身就是一种拖延。

所以这个站点诞生了。它很简单：

- 用 Markdown 写文章
- 用 Vite + React 构建
- 部署在 GitHub Pages 上

没有后端，没有数据库，没有评论系统。就像一张纸和一支笔，只是用来记录。

## 我会写什么

大概是这几类内容：

1. **技术笔记** —— 前端、工程化、工具链
2. **产品思考** —— 独立开发路上的踩坑与感悟
3. **生活碎片** —— 读书、旅行、咖啡与城市散步

> 「写作是为了理解自己所想。」—— 这句话我忘了是谁说的，但很有道理。

希望这里能成为一片安静的角落，也欢迎你偶尔路过。
